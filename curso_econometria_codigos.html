Presentación

Esta página reúne códigos básicos de Econometría para estimación, diagnóstico y análisis de series de tiempo.

Los códigos pueden adaptarse a bases de datos del BCRP, INEI u otras fuentes.

1. Python: regresión lineal

import pandas as pd
import statsmodels.api as sm

df = pd.read_csv("datos.csv")

X = df[["x1", "x2"]]
X = sm.add_constant(X)
y = df["y"]

modelo = sm.OLS(y, X).fit()
print(modelo.summary())

2. R: regresión lineal

datos <- read.csv("datos.csv")
modelo <- lm(y ~ x1 + x2, data = datos)
summary(modelo)

3. Stata: regresión lineal

import delimited "datos.csv", clear
reg y x1 x2

4. Series de tiempo: prueba ADF en Python

from statsmodels.tsa.stattools import adfuller

serie = df["y"].dropna()
resultado = adfuller(serie)

print("ADF:", resultado[0])
print("p-valor:", resultado[1])

5. Modelo ARIMA en Python

from statsmodels.tsa.arima.model import ARIMA

modelo_arima = ARIMA(serie, order=(1,1,1))
resultado = modelo_arima.fit()

print(resultado.summary())

Interpretación básica

  • p-valor < 0.05: evidencia estadística significativa.
  • R²: proporción de variación explicada por el modelo.
  • ADF con p-valor < 0.05: la serie puede considerarse estacionaria.
